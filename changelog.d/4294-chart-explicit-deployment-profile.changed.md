- The Helm chart, at a new major version (21), has no default deployment profile: it refuses to render until `config.deployment_profile` names `sandbox` or `production`, so an installation that follows a quickstart instead of the instructions for use no longer runs the sandbox posture by omission (EHDS Annex II 1.2). A values file that relied on the old `sandbox` default must now set it, for example `--set config.deployment_profile=sandbox`; `values-production.yaml` sets `production` as before. The server binary's own default and the Compose files, which declare `sandbox` explicitly, are unchanged.
