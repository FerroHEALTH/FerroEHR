- FerroEHR ships an EHDS category map for the published CKM templates and COMPOSITION archetypes whose data sit in one Art. 14(1) priority category (the International Patient Summary, ePrescription, the generic laboratory result and CCTA report templates; the `health_summary`, `prescription` and `transfer_summary` archetypes), so an installation that declares no `[audit.categories]` keys records those accesses classified instead of `unclassified` (EHDS Annex II 3.2(c)). A deployment that declares any template or archetype replaces it whole. `[audit.categories] shipped_map = false` with nothing declared leaves no map, which `deployment_profile = "production"` refuses as the new `no_category_map` gap unless `deployment_accepts` names it.
