- An AQL `EHR e[ehr_id/value='…']` predicate whose value is not a UUID (`'1234'`, the AQL 1.1.0 example) answers an empty result, as its `WHERE e/ehr_id/value = '…'` spelling does, on `POST` and `GET /query/aql`; it was refused with `400`. Both spellings lower the EHR id comparison through one path, and a value the database cannot cast is refused with a message that no longer claims it came from a query parameter.
