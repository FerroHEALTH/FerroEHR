- The local EHR index (`[ehr_index] provider = "local"`) is a supported production posture beside the IHE patient identity source: `EHR_STATUS.subject` names a patient by its own namespace and identifier, which `GET /ehr?subject_id=&subject_namespace=` matches, and with no `[privacy] subject_namespaces` declared the reference is stored as the client sends it. The compose quickstart selects it with `FERROEHR_EHR_INDEX=local docker compose up`, which runs its `ferroehr-config-local` block.
