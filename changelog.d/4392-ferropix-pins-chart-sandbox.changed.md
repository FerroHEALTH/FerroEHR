- The Helm chart runs FerroPIX 0.0.12 by digest, with the FerroPIX chart 0.3.4 built for it, and the hosted sandbox runs FerroPIX 0.0.12 too; both had stayed at 0.0.7 and 0.0.10 when the quickstart moved. A values file for the chart's FerroPIX moves `ferropix.config.server.public_base_url` to `ferropix.config.public_base_url` and each issuer's `clients` to `ferropix.config.trust.issuer`, the keys FerroPIX reads since 0.0.8; the chart's examples and the production overlay do. FerroPIX's chart now also runs its pods with `enableServiceLinks: false` and in a user namespace (`ferropix.hostUsers: false`, the default). A CI guard holds the quickstart, chart and sandbox to one FerroPIX release and checks the sandbox's and the chart's FerroPIX configuration under it, so the Dependabot proposal for the quickstart pin moves all three.
