- `scripts/conformance.sh` runs the Veredictum 0.3.0 catalogue against one FerroEHR deployment: it reviews the party statement with `veredictum validate`, drives `veredictum test` in the release image pinned by digest with Basic login, and writes `results.json`, the HAR recording and the JUnit, CTRF and Markdown views to `docs/conformance/ferroehr/`. Docker or Podman runs it (`CONTAINER_ENGINE`). The FerroEHR statement now claims the 15 capability folders and answers every option of the 0.3.0 catalogue, and the IXIT keeps only what 0.3.0 reads.
