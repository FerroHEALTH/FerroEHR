- AQL `TERMINOLOGY('expand', …)` against a FHIR terminology server takes the value set from the `url` argument when `params_uri` is the `$expand` query form (`url=http://…`), as the openEHR AQL examples write it, and still takes a bare value-set URL as it is. A query form without `url` is a 400 that names the missing argument. Before, the whole `params_uri` went to the server as the URL, and the query was answered 400 because the value set was not found.
