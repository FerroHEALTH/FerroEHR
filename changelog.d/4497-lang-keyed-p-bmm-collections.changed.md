- **The P_BMM model follows SPECLANG-16.** The LANG 1.1.0 BMM that `openehr-codegen` reads is now the `specifications-LANG` file at `f80763ab`, so `P_BMM_SCHEMA.primitive_types` and `class_definitions` are maps keyed by class name, `P_BMM_CLASS.ancestor_defs` is a map of `P_BMM_BASE_TYPE` keyed by type signature (a simple ancestor included), and `P_BMM_GENERIC_TYPE.generic_parameter_defs` is an optional map keyed by formal parameter name. The formal and actual generic parameters (`P_BMM_CLASS.generic_parameter_defs`, `P_BMM_GENERIC_TYPE.generic_parameter_defs`, `BMM_GENERIC_CLASS.generic_parameters`) are insertion-ordered `IndexMap`s, because the specification fixes their declaration order, and the model builders bind each actual parameter to its formal by name. In the released `v1_0` generation, `P_BMM_GENERIC_TYPE.generic_parameter_defs` now carries the `1..*` bound its BMM states. The nine `openehr-*` crates step to 0.0.123.
