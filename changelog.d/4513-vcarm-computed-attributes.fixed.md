- **ADL 2 validation admits a constraint on an RM computed attribute.** VCARM accepts an attribute "stored or computed" (AOM2 `master04.5` §Validity Rules: `C_ATTRIBUTE`), and a function with no arguments is a computed attribute (`master04.2` §Attribute Nodes), so an archetype that constrains `DV_PROPORTION.is_integral`, `DV_QUANTITY.is_integral` or `EVENT.offset` is no longer refused with `422`. The generated RM model (`openehr_rm::v1_2::model`) now carries each class's computed attributes from the BMM functions (`RmClass::computed_attributes`, `computed_attribute`). `openEHR-EHR-CLUSTER.microscopy_prostate_carcinoma.v1.0.0` from the 2013 CKM ADL 2 export now uploads, and the sandbox archetype-library pin moves to 232 accepted and 90 refused. `DV_QUANTITY.property`, which no RM release defines, stays refused.
