- An ADL 2 archetype reference resolves to one defined stored release: an interface reference (`….v1`) takes the newest release of its major version, a reference with a minor or patch version narrows the match to it, and an alpha or beta version matches only its full identifier (BASE Artefact Identification, Referencing). With several releases of one archetype stored, a template upload, an operational template and the delete's dependents check used whichever release PostgreSQL returned last, and a reference to a major version no stored release carries resolved to another major version.
