- An ADL 2 upload and an ADL 2 delete no longer race. An upload validated before a concurrent delete of an archetype it uses committed could store a template whose constituent was gone. Both now hold one transaction-scoped advisory lock from the repository read to the commit, so the second write decides on what the first committed: an upload after the delete is refused with `VARXR`, and a delete after the upload is refused with a `409` naming the template.
