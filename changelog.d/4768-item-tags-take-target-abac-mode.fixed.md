- The ABAC policy-enforcement point checks every item-tag operation as it checks its target: a COMPOSITION tag read after the call like the COMPOSITION read, a COMPOSITION tag write before the call with the tagged version's template, category and origin, and the EHR tag read before the call like the EHR read. These operations were unchecked before, so a patient-scoped or template-scoped rule now refuses a tag read or write wherever it refuses the target's read or write. A COMPOSITION tag read also falls under the `EHR_ACCESS` privacy ceiling and its audit record names the tagged COMPOSITION.
