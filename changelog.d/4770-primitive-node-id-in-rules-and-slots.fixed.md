- A primitive constraint inside a rule or a slot assertion of an id-coded ADL 2 archetype carries `id9999` as its node id, as `org.openehr.am.aom2.adl_code_definitions` §Constants defines `Primitive_node_id` for id-coded archetypes, where it carried `at9999` before. An ADL 1.4 archetype converted to ADL 2 recodes its slot assertions the same way. `openehr_adl::rules::parse_rules_body` and `parse_slot_assertions` take the archetype's `NodeCoding`, which `openehr_adl::codes` now exports.
