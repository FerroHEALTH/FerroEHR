- Under the `development` profile, `POST /definition/template/adl2` refuses with `400` a template whose description has no `original_author` or an empty `lifecycle_state`, naming `RESOURCE_DESCRIPTION.Original_author_valid` or `RESOURCE_DESCRIPTION.Lifecycle_state_valid`. BASE 1.3.0 states both invariants (`org.openehr.base.resource.resource_description.adoc` §Invariants). The `stable` profile's BASE 1.2.0 states neither, so it still accepts such a template.
