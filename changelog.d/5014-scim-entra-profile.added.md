- The SCIM endpoint answers the Microsoft Entra ID provisioning client as Microsoft's "Develop a SCIM endpoint" guide documents it: a value-filtered attribute such as `emails[type eq "work"].value` serves its `type` and declares `primary` read-only, so the `primary` Entra sends is ignored (RFC 7644 §3.3); a `PATCH` of `userName` renames the User; and the Test Connection probes are answered with an empty `ListResponse` and `404`. `ferroehr config check` refuses a `[scim]` the person mapping cannot serve, as `serve` does. The Helm chart exposes `config.scim` and routes `/scim/v2` on every Ingress host when it is enabled, and the book walks an operator through provisioning from Entra ID, with the Workload Identity Federation checks the authorization server makes.
