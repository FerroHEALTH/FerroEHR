- An AQL `VERSION` standard predicate on `commit_audit/time_committed` applies its operator: `VERSION v[commit_audit/time_committed/value > $t]` returns every version committed after `$t`, where it returned the trunk version current at `$t` whatever the operator (QUERY 1.1.0 master03 §Standard predicate). A number, boolean or `NULL` literal as the bound, a string bound no ISO 8601 form reads, and a `time_committed` path other than the whole value or `/value` are refused with `400`.
