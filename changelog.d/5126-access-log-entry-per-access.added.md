- Every access to EHR data now writes an openEHR access-log entry (the draft `ACCESS_LOG_ENTRY`) beside its audit record, in the same transaction: reads, writes, AQL queries, exports, refusals and reads of the access log through ITI-81, one entry per EHR an access reached, joined by the request id. An entry names the version, the categories and origins, the party, the purposes and the authorisations, and never a data value of the EHR or the query text, which it names by digest.
