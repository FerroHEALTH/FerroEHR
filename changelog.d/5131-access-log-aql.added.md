- The openEHR access log can be queried with AQL as the top-level class `ACCESS_LOG_ENTRY` on the Query API, with paths over the entry, `WHERE`, `ORDER BY` and paging. The class stands alone in `FROM`: a query that puts it inside an `EHR` containment, or an `EHR` inside it, answers `400` naming the rule. Who may run it follows the access log's own resources: a caller the admin class admits reads every EHR's entries in the full view, the patient and their bound representative read their own EHR's entries in the subject view, where a withheld path reads as absent, and anyone else gets `403`. Every such query writes its own access-log entry.
