- `openehr-rm` types generic RM type names and paths: `typing::RmType` parses and prints names such as `DV_INTERVAL<DV_QUANTITY>`, `typing::attribute_type` gives an attribute of an instantiated class with the actual argument in place of the formal parameter, and `typing::path_type` types every step of an `RmPath` with its container. Each `model::RmAttribute` and `model::RmTypeRef` keeps the formal parameter it is written as (`formal`) beside the resolved bound. `paths::write::item_at_path_mut` and `paths::write::set_at_path` write at a path into a canonical instance, positional predicates included, creating the members the path names and changing nothing when a write is refused.
