- An `Interval` or `DV_INTERVAL` read from canonical JSON or XML that omits a boundedness or inclusion flag now takes it from its bound. An absent bound reads as unbounded and not included, and a present bound as bounded and included. A flag the wire states is kept as written. Before, an omitted flag always read as bounded and included, so an interval with only an `upper` came out with a bounded, included lower side that had no value. ITS-JSON requires all four flags, and BASE ties none of them to its bound, so reading the omission is our own design.
