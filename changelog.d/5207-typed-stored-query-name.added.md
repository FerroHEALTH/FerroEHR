- `openehr-its`: `rest::stored_query` types a stored query's qualified name (`QualifiedQueryName`, `[{namespace}::]{query-name}` with `aql` reserved), its version (`QueryVersion`, `major.minor.patch` in numeric order) and the version pattern a request addresses (`VersionPattern`, exact, `{major}` or `{major}.{minor}`, selecting the highest match), per ITS-REST 1.1.0. The generated stored-query operations and the `StoredQuery` and `RESULT_SET` documents carry them, so a name or version outside the grammar is a `400` where the request is decoded.
