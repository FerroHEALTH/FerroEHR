- A Web Template keeps the `time` of a single `EVENT` that the level removal collapses. ITS-REST simplified formats master04, §"Conditionally Collapsed Wrapper Types", collapses an `EVENT` with occurrences `0..1` into its OBSERVATION, and the builder dropped the event's RM-mandatory `time` with it (RM data structures, `EVENT.time` 1..1). FLAT and STRUCTURED had no key for the event time, so a written time was lost and read back as the history origin. The OBSERVATION now carries an in-context `time` leaf at the event's own path (`…/events[at0002]/time`). It builds into that event and reads out of it, as a retained event's `time` does. In `openehr-sdt`.
