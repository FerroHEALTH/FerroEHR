- `openehr-sdt` exposes the slot admission decision as `WebTemplateArchetypeSlot::admits(rm_type, archetype_id)` (AOM 1.4 `ARCHETYPE_SLOT`): the filler type conforms to the slot's RM type, the id matches an include pattern and no exclude pattern, and a match-all exclude beside includes is the ADL 1.4 closed-slot idiom. The Web Template validator uses the same method, so a consumer such as FerroBRIDGE no longer needs a copy of the matcher.
