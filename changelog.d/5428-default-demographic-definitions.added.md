- FerroEHR ships a complete default set of demographic definitions under `deploy/definitions/`: the professional `PERSON` and `ROLE`, a care-team `GROUP`, and the membership and representation `PARTY_RELATIONSHIP` archetypes the party mapping names, each adapted from openEHR CKM archetypes with a `PROVENANCE.md` naming its sources. The quickstart, the hosted sandbox, the conformance harness and the Helm chart's default `definitions.files` (chart 25.1.0) load all five, every release attaches each file with a `.sha256sum`, and the book's new "Default demographic definitions" page lists them with the keys that name them. A deployment may load its own templates instead; the mapping the quickstart, the sandbox and the chart's overlays configure is unchanged.
