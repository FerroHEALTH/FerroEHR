- FerroEHR ships a complete default set of demographic definitions under `deploy/definitions/`: the professional `PERSON` and `ROLE`, a care-team `GROUP`, and the membership and representation `PARTY_RELATIONSHIP` archetypes the party mapping names, each adapted from openEHR CKM archetypes with a `PROVENANCE.md` naming its sources. The quickstart, its Keycloak overlay, the hosted sandbox, the development lanes and the conformance harness load all five and map them, so SCIM Users, Groups and representation work out of the box; the Helm chart's default `definitions.files` (chart 25.1.0) loads them and leaves the party mapping to the operator. Every release attaches each file with a `.sha256sum`, and the book's new "Default demographic definitions" page lists them with the keys that name them. A deployment may load its own templates instead.
