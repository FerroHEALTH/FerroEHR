- A demographic AQL query by a caller without `[authz.rbac] admin_role` no longer returns policy parties. A query under any demographic root, alone or under `VERSION`, leaves out every version of a policy party, together with every node it reaches inside them through `CONTAINS` or a path. The rule is part of the query's one SQL statement, so `COUNT`, the other aggregates and paging count only the parties the caller may read, and no extra statement runs. An administrator's query returns them, as the Demographic API read does. The book's "Operational policy" page states the rule.
