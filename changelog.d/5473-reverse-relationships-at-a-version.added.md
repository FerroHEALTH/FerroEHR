- `GET /ferroehr/rest/extensions/v1/demographic/party/{uid_based_id}/reverse_relationships` evaluates the RM 1.2.0 function `PARTY.reverse_relationships()` in either specification profile: a JSON array of the `LOCATABLE_REF`s a stable-profile party read carries, as they stand now or, for a version id or a `version_at_time`, as they stood at that version's commit. No ITS-REST resource serves the function, so this is a FerroEHR extension.
