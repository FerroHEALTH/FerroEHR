- **`openehr-rm` gains a `draft` feature, off by default:** `openehr_rm::draft` holds FerroEHR's draft change proposals to the RM, the access log (`draft::access_log`) and access control (`draft::access_control`), generated from their draft BMM, with the class invariants each states (`draft::invariants`, `draft::<package>::invariants`). They are no openEHR release and can change in any version. A build that does not enable the feature sees no draft type.
