- The access log is signed whenever `[record.signing]` holds an OpenPGP key: every link is signed and written with its record in one `INSERT`, and the server writes a signed checkpoint every five minutes when the chain grew; without a key nothing is signed or sealed. `[audit.access_log] checkpoints`, `checkpoint_interval` and `sign_links` are gone and refused as unknown keys. Use an Ed25519 signing key: RSA signing is far slower, and every audit write waits on it. Migration `audit/0029` writes the signature at insert and takes back the update that set it afterwards.
