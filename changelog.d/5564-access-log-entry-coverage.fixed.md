- An AQL statement that projects only the EHR, with no `CONTAINS COMPOSITION` (`SELECT e/ehr_id/value FROM EHR e`), now writes one access-log entry per EHR it served, so the subject's access log shows the query. Archiving and restoring an EHR, its retention anchor and object hold, the repository dump and load, and each EHR the bulk physical delete removes now write an entry per EHR as well. The import of another system's access log (`ferroehr access-log import`) writes its entry through the same path as every other entry; its accessor is now the system identified by its login. The performance gate seeds a population (`PERF_POPULATION`, 2 000 EHRs, 20 000 in the release lane) for its population query and reports the access-log entries it wrote per statement against the base (#5564).
