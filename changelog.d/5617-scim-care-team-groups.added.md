- A SCIM Group is a care team when its client creates it with `careTeam = true` in FerroEHR's Group extension, `urn:ietf:params:scim:schemas:extension:ferrohealth:2.0:Group`, which `/Schemas` and `/ResourceTypes` list. `careTeam` is immutable. The Group's `GROUP` carries the new `ferroehr-operations::care_team` code (group `group kind`) and each membership carries `member_of`, so the members count as the team's care team for access decisions. Creating a care-team Group and changing its members needs the client's `write_care_relationship` grant in the CDR. The default `openEHR-DEMOGRAPHIC-GROUP.care_team.v1.0.0` and `openEHR-DEMOGRAPHIC-PARTY_RELATIONSHIP.membership.v1.0.0` definitions each gain an optional coded element for the code.
