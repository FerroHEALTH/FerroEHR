- The access log no longer grows without end past its retention. A tombstone is kept as long again as its entry was, and then the hourly retention run folds each run of consecutive tombstones past their end into one gap of the chain (`audit.access_log_chain_gap`, migration `audit/0033`). The gap keeps the positions the run held, the link and link signature of its last record and the grounds of its tombstones, and it is the record of the fold. A run is cut after each checkpoint's position. `audit.verify_access_log_chain()`, its incremental form, `ferroehr access-log verify`, `POST /admin/access-log/verify`, the export and the import verify across a gap, and a record deleted any other way is still reported as tampering. An erasure a law orders folds the same way. `GET /admin/access-log/chain` answers the span's `gaps` beside its `links`, and an export carries `gaps`, which an import keeps; an export written before this release no longer reads. New metrics: `access_log_folded_total` and `access_log_gaps_total`. No configuration key was added or removed.
