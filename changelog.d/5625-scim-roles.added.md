- **SCIM User `roles` are `ROLE`s the access policy's rules name.** Each value of a User's `roles` (RFC 7643 §4.1.2) becomes one `ROLE` its `PERSON` performs. The `ROLE` is named by the value, coded in the `role_terminology` of the client's `scim_provision` grant, and its validity starts the day it is added. A removed value ends its `ROLE` and decides the next request. The grant's `role` elements list the codes the client may assign. Any other code, and any role when the grant names no `role_terminology`, is refused `403`. The User schema now serves `roles`. The `scim_provision` grant gains the `role_terminology` element, which is required when the grant lists a `role`.
