- **The access log's coded filters take a term's coded content.** `action`, `outcome` and `accessor_kind` on `GET /ehr/{ehr_id}/access_log`, and `outcome` on `GET /admin/access-log`, take the FHIR token `terminology_id|code` of the term's `defining_code`, such as `audit-event-action|R`, `openehr_access|refused` or `extra-security-role-type|datasubject`, and select by that code. A rubric, a bare code, a terminology the group holds no term of, or a code outside the group is a `400`. AQL over `ACCESS_LOG_ENTRY` reads `action/defining_code` and `outcome/result/defining_code` from the search columns. Audit migration `0035` replaces the `action` and `result` columns of `audit.access_log_record` with the terminology id and code of each and recomputes them from the stored records; no digest changes.
