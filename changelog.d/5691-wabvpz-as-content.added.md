- **Controller rules name callers by their organisation's type.** An actor scope's `organisation_type` matches a caller acting for an `ORGANISATION` whose `name` is that code, compared by terminology and code. Party migration `0046` holds each organisation's type as a caller fact, and the first boot after it refills them before it serves.
- **A partner's attested roles and facility types count for the rules.** A caller admitted under a federation agreement performs the professional roles its token attests in `professional.hp_professional_role` and acts for an organisation of each type it attests in `provider.facility_type`, each a code of the system the value names, so one rule binds a local and a partner's professional alike. A value that names no system matches no rule.
- **A refusal by a controller rule names its legal grounds.** The `403` problem body carries the refusing rules' `legal_grounds` beside `refusal` under `Prefer: return=representation`, and the access record names each refusing rule as a `legal obligation` ground with its legal grounds.
