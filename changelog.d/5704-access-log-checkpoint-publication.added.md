- `[audit.access_log] publish_directory` (`FERROEHR__AUDIT__ACCESS_LOG__PUBLISH_DIRECTORY`): the server publishes the newest access-log checkpoint every 30 seconds as its own write-once file in a directory outside the database, the recommended setup, since only a published checkpoint shows that the newest entries were removed together with the checkpoints that seal them. The new `access_log_checkpoints` health indicator reads `DEGRADED` without a signing key, without the directory, or while publication fails; readiness stays `200`.
