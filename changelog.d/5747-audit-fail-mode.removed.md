- **Breaking: `[audit] fail_mode`, `[audit] queue_capacity`, `[audit.store] enabled` and `[audit.syslog] spool_dir`, `spool_max_events` and `spool_max_size` are removed** (#5747). A configuration that still sets one refuses boot as an unknown key. No fail mode exists: an access whose record cannot be written is refused. The local store is always on while auditing is, and a `--no-default-features` build refuses `[audit] enabled = true`. The deployment gap `audit_fails_open` is removed, so `deployment.accepts` naming it is refused. The metrics `atna_audit_dropped_total` and `audit_drain_queue_depth` are removed. The Helm chart 36.0.0 drops `config.audit.fail_mode` and `config.audit.store.enabled` from its production overlay and CI values (a major bump: a values file that sets either is refused at boot).
