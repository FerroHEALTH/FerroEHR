- A request allocates less memory. Its capabilities share the grant copy's credentials and client instead of copying them, the grants are resolved once per request instead of twice, the caller's principal is shared across the request, the ITS-REST route templates are split once instead of on every request, and a commit no longer copies the body for the signature, the node write and the `ORIGINAL_VERSION` envelope or builds a path string for every node the privacy scan visits (#5754, #5757, #5759). Nothing a client or an operator sees changes.
