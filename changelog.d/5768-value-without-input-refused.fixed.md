- A FLAT or STRUCTURED write that gives a value on a node with no value of its own is refused with `422` instead of losing the value. A key such as `…/choice: 5` on an ELEMENT whose template allows several value types was dropped: alone it failed later with an RM invariant at a canonical path, and beside a `…/choice/_null_flavour` it was stored with `201` as null-flavoured. ITS-REST simplified formats master05 puts a value on a data value node and master04 §Validation checks field identifiers against the Web Template, so the refusal now names the key and, for such an ELEMENT, the alternatives the value belongs on (`…/choice/quantity_value`, `…/choice/coded_text_value`). A structural node given a bare value is refused the same way. A bare `DV_PROPORTION` value, its magnitude (master05 §DV_PROPORTION, "calculated on output"), is refused when it disagrees with `numerator / denominator` at the decimals it is written with, where it was ignored before.
