- A request's access-log entries are written in one statement that commits on its own (#5770): the search tokens, the shared sets and the intake rows of `audit.access_log_intake_take()`, with no BEGIN, COMMIT or separate token statements. Two intake writers gather the entries of every waiting request into each statement, so under load one commit and one flush of the write-ahead log serve many requests. Each request still answers only after its own entries are durable.
