- An ODIN terminology code in an ADL2 `_default`, such as `defining_code = <[snomed_ct::163033001]>`, is read as the RM `CODE_PHRASE` it denotes (`terminology_id` a `TERMINOLOGY_ID`, with a stated version as `name(version)`, and `code_string`) instead of the string `"snomed_ct::163033001"`. The ADL2 printer writes such a `CODE_PHRASE`, or a list of them, back as ODIN term codes. A `(json)` default is kept as written.
