- `openehr-rm` adds `canonical_serializer_impl` to both generations. `canonical_to_string` and `canonical_object_without` write the RFC 8785 canonical form of any `Serialize` value without building a `serde_json::Value`, byte-identical to `canonical_json(&serde_json::to_value(x))`. `CanonicalObject` assembles a canonical object member by member. FerroEHR's access-log intake and `canonical_form` use them, so an entry's canonical form, its stored parts and its derived columns come from one write of the entry. Computing an entry's intake form takes about 40 % less CPU.
