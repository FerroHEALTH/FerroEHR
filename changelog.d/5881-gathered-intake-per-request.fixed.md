- A request whose access-log entries are gathered into one intake statement with other requests' is answered by its own outcome. A statement the database refuses as a deadlock or serialization failure runs again, up to three times. Any other refusal writes each request on its own, so one bad entry refuses only its own request. A failure the database did not answer still refuses every request it gathered. The intake statement inserts the search tokens, shared sets and shared parts in the order of their keys.
