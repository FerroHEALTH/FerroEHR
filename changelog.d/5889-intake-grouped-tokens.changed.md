- The access-log intake statement groups every entry's search tokens in one pass and finds them by digests the server computes (migration `audit/0044`), so its cost grows with the tokens of a batch, not with its entries times its tokens. With every token and shared set already stored, the statement now runs three statements of its own instead of nine. No configuration key was added or removed.
