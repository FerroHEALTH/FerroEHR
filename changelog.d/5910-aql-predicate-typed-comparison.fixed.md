- A comparison in an AQL class-expression or node predicate answers as the same comparison in `WHERE`. `CONTAINS ELEMENT el[value/magnitude > 1000]` compared the stored value and the operand as text, so it kept 120, 80 and 5 and `el[value/magnitude < 100]` kept none, with no warning. A predicate now reads its leaf with the type the RM gives it: numbers compare as numbers, a date/time as the instant it names and a whole data value with a value of its own kind. A value the leaf cannot compare with, and a predicate path the RM does not define on the node, are refused with `400`.
