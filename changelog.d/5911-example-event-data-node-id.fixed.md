- A composition built from FLAT, STRUCTURED or an example gives an event's `data`, and an activity's `description`, the node id and type the template constrains. Since the single-event `time` fix of 5.7.1-rc1, an OBSERVATION whose one event holds only an archetype slot got its event `data` as an `ITEM_TREE` with the placeholder `at0001`, so FerroEHR's own `medium` and `complete` examples of such templates were refused "unexpected node 'at0001' under 'data'". The placeholder now stays only where the template leaves the attribute unconstrained.
