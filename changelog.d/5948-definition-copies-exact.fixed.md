- **A template or ADL2 artefact changed on one instance decides the next request on every instance.** After a template was deleted or replaced on one instance, the other instances validated FLAT and STRUCTURED commits and served `wt+json` from the Web Template they had built before, until a restart. An ADL2 artefact written on one instance reached AQL archetype predicates on the others only after a one-minute time-to-live. Each request now reads a definition revision in the read of the policy heads it already makes, and drops the copies built before a change, with no added statement. A failed read of the archetype lineage now refuses the query with `503` instead of answering it with fewer matches.
