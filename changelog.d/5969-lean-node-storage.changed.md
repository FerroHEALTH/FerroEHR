- A composition commit writes less to the database. The node rows of a version no longer carry a foreign key into the version table, which ran one nested lookup per row (402 on the IPS composition). Two node indexes now cover only the rows their queries read: the per-EHR class index leaves out ELEMENT rows, and the archetype index keeps only rows with an archetype id. The storage-parity sweep (`POST {ext}/admin/integrity/verify`) reports a new defect, `orphan_nodes`, for node rows that no stored version reads, and the node rebuild (`POST {ext}/admin/integrity/rebuild-nodes`) deletes them. Migrations `clinical/0052_node_lean.sql` and `party/0054_node_lean.sql` make the change.
