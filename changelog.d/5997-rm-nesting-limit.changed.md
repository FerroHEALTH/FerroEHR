- The canonical-JSON and canonical-XML RM readers share one nesting limit of 48 RM objects (`openehr_base::nesting::MAX_RM_NESTING`), and a document at that limit reads on a 2 MiB thread in a debug build (`MIN_RM_READ_STACK_BYTES`). A deeper document is refused with a parse error. Each nested level now takes about 1.6 KiB of stack in a release build for JSON (was 37 KiB) and about 6 KiB for XML (was 20 KiB).
