- A population AQL query filtered on the code of an ELEMENT value reads the rows the filter keeps. Such a query used to read every node of the archetype and compare the code last: a lookup of the one composition of 400 that carries a code (`WHERE o/data[at0001]/events[at0002]/data[at0003]/items[at0005]/value/defining_code/code_string = $code`) read 8,565 buffers and now reads 36. A top-level equality on `value/defining_code/code_string` of a DV_CODED_TEXT, or on `value/symbol/defining_code/code_string` of a DV_ORDINAL or DV_SCALE, enters through the new index `idx_node_hot_value_code`; the answer is unchanged. The index adds write-ahead log to a commit that carries coded values, 72 bytes for each, 1.08% on the IPS composition. The migrations `ext/0015`, `clinical/0055` and `party/0057` create the function and the index and analyze `node_hot`; on a large store the index build takes its time at upgrade.
