- **The national identifier scanner is removed.** The data-minimisation pass no longer reads clinical values for the shape of a national identifier: the eight checksum rules (`ch-ahvn13`, `ch-epd-pid`, `de-kvnr`, `fi-hetu`, `gb-nhs-number`, `nl-bsn`, `no-fodselsnummer`, `se-personnummer`), the custom `patterns`, the `warn` mode and its `privacy_warn` count on the validation-failure metric are gone. Every checksum accepts a share of random digit runs, so the scanner refused valid laboratory data such as a filler order number that passes the Swedish personnummer check; a clinical value is now stored as written. `[privacy.identifier_scan]` is an unknown table, and a configuration that still sets it, in the file or as `FERROEHR__PRIVACY__IDENTIFIER_SCAN__*`, is refused at boot naming the key. The subject-reference rule and the identified-party rule are unchanged.
