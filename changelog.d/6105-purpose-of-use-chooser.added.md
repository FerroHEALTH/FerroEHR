- `GET {extensions}/access/purposes` lists the purposes of use a caller may declare: the `[audit] purpose_header`, the new `[audit] purpose_system` (default HL7 `ActReason`) and each `[audit] purpose_codes` entry with the display text the terminology server gives it. Any authenticated caller reads it, one with no role included, since it names no personal data. The viewer declares a purpose on every CDR request: the one its reader chooses on Preferences, kept for the session, or `[cdr] purpose_of_use`, which must be a code the CDR lists (#6105).
