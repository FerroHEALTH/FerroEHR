- An EHR create no longer waits for a party connection while it holds its audit and clinical connections. The access decision on the new EHR reads the subject's `PERSON` and the caller's care before the create takes its write connections, so concurrent creates naming subjects in another namespace no longer stack up on the pools until they are refused `503`. `db_pool_nested_acquires_total` now also counts, with `order="inside_a_write"`, a write that asks the other domain's pool for a connection, which a debug build refuses.
