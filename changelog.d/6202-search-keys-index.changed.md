- The ITI-81 token index of `audit.audit_event` and of `audit.access_log_entry` is a GIN index of `audit.search_keys`, which holds a record's search tokens and a key for each of its request id and touched resource id. It replaces the two hash B-tree indexes on `request_id` and `resource_id` of each table, so a record writes one index entry where it wrote three. Measured with full-page writes off, an access-log entry writes 96 to 105 fewer bytes of write-ahead log (2634 instead of 2730 for a composition read, 1777 instead of 1876 per entry of a population query) and a system audit record 96 fewer. `entity` and an `entity.identifier` that names a request id or a created version uid answer through the GIN index, and the search compares the text as before.
