- Retention no longer deletes a search token a live access-log entry names. Reaping the last system audit record that named a token deleted it, although access-log entries still named its id, so an ITI-81 search on that token (an `agent.identifier`, an `address`) stopped finding those entries. The retention check and the trigger that guards `audit.audit_search_token` now read the access log's token index as well.
