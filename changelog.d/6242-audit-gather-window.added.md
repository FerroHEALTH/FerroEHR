- `[audit.store] gather_window` (`FERROEHR__AUDIT__STORE__GATHER_WINDOW`, at most `"1ms"`, default `"0s"`): how long the gathered access-log writer waits for more requests' entries after the first before it writes them in one statement. When every search token, shared set and shared part of a batch is known, the batch is written by one plain insert with no database function around it.
