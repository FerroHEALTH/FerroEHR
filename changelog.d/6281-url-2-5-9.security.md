- FerroEHR takes `url` 2.5.9. In 2.5.8, `Url::origin()` called itself once
  for each `blob:` prefix of a URL with no depth limit, so a URL of a few
  tens of kilobytes overflowed the stack and aborted the process
  (RUSTSEC-2026-0592, GHSA-hrj5-67jp-wqp9, CWE-674). FerroEHR calls it only
  in the viewer, on configured URLs and on URLs that already start with a
  configured `http(s)` root, so no path reached a nested `blob:` URL; the
  upgrade closes the advisory.
