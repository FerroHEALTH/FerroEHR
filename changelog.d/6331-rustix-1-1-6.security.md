- FerroEHR takes `rustix` 1.1.6. In 1.1.4 the extended-attribute functions
  of `rustix::fs` marked as initialized the size the kernel reported for a
  zero-length buffer, which it never wrote, so a caller could read
  uninitialized memory from safe code (RUSTSEC-2026-0486,
  GHSA-jh2m-fhpj-3vr7). No shipped build calls those functions: their one
  caller is the test harness's container tooling; the upgrade closes the
  advisory.
