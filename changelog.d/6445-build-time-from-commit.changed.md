- **The build time a server reports is its commit time.** `/management/info` and `ferroehr_build_info` report `SOURCE_DATE_EPOCH` when the build sets it, as before, and otherwise the commit time of the built checkout in place of the moment of the build, so two builds of one commit report the same time. `unknown` stands for a build with neither. An unchanged tree no longer reruns the build script, so a second build compiles nothing.
