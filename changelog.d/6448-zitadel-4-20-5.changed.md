- The ZITADEL example runs ZITADEL v4.20.5 and its Login v2 UI at v4.20.5
  (`ghcr.io/zitadel/zitadel:v4.20.5@sha256:cb21fe73…`,
  `ghcr.io/zitadel/zitadel-login:v4.20.5@sha256:bbab3b26…`), with the vendored
  ZITADEL documentation moved to the same tag. The two releases fix the login
  (an OTP SMS resend cooldown, PKCE by default for the Google, GitHub, GitLab
  and Azure AD identity providers, the configured second factor required
  before an authenticator is added); none changes the configuration the
  example sets.
