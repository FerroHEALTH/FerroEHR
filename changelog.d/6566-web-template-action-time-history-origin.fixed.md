- The Web Template now carries an in-context `time` (`DV_DATE_TIME`, 1..1) under every ACTION and an in-context `history_origin` (`DV_DATE_TIME`, 1..1) under every OBSERVATION, at `<observation>/data[<history node id>]/origin`. A client that places paths against the Web Template can now address `ACTION.time` and `HISTORY.origin`, with the same keys the FLAT format has always accepted (`<action>/time`, `<observation>/history_origin`). An example composition writes `history_origin` only when its HISTORY also holds an event.
