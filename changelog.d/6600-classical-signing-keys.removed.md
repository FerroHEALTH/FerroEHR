- **Breaking: signing with a classical OpenPGP key is removed.** The server no longer chooses a classical signing subkey or primary key, and no longer boots with an Ed25519, EdDSA or RSA signing key (with or without the RSA advisory warning); `pgp` mode signs only with ML-DSA-65+Ed25519 (RFC 9980 algorithm ID 30). Classical certificates stay readable as `retired_key_files`, so stored signatures keep verifying (#6600).
