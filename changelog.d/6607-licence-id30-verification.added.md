- The licence check verifies a token signed by an ML-DSA-65+Ed25519 key (RFC 9980 algorithm ID 30) beside the licensor's Ed25519 keys, through the same OpenPGP verification path as the version signatures: a version 6 key with a valid direct-key self-signature, a signature that names the key by fingerprint, a digest of at least 256 bits (RFC 9980 §5.3.1, refused as `WeakDigest` before any cryptography) and both halves verifying (§3.2). A signature over MD5, SHA-1 or RIPEMD-160 is refused for any key (RFC 9580 §9.5). The shared ID 30 vectors under `corpus/openpgp-id30/` give the same answer here as in every other verifier of these tokens (#6607).
