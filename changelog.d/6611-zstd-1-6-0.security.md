- The server binary links Zstandard 1.6.0 through `zstd-sys` 2.2.0. Releases 3.0.0 to 5.7.0 compiled in Zstandard 1.5.7, whose decoder could expose its internal buffer (up to 64 KiB of uninitialised memory or earlier decompressed data) through the output of crafted compressed data (CVE-2026-124851, GHSA-65wm-j22v-56c3). FerroEHR reached that decoder when its outbound HTTP clients decompressed a `zstd`-encoded response, so a server it calls could send such data. The judgement per release is in `security/vex/rust-releases.openvex.json`. The `libzstd1` package of the distroless base is never loaded by either program (`security/vex/ferroehr-os.openvex.json`).
