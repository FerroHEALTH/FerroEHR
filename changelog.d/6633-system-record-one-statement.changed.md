- A system audit record is written in one statement, its search tokens resolved in the same statement (`audit.search_tokens_of`), where it took five round trips (`BEGIN`, the token hold, the token statement, the insert, `COMMIT`). **Breaking for anyone recomputing a system record's content digest outside FerroEHR:** the digest form is now `ferroehr.audit_event.v8` (`digest_version` 8), which leaves out `search_tokens`, the store-internal ids of the record's search tokens. Every other column is digested as before.
