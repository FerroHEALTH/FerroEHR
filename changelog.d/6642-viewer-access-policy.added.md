- The viewer's new **Access policy** page, in the console group, shows the controller's access policy in force by section: classifications, controller rules, catalogue, care relationship facts, purpose of use, conflict rules, concealed confidentialities, log restrictions and value sets, each coded value with its rubric and code. Its **Versions** tab lists every version with its committer and commit time and opens any one read-only. An administrator edits the whole policy in the code editor, and the save names the version it replaces in `If-Match`. While no policy is committed, the page says that nothing is tightened. A `403` or an admin API that is off is drawn as such ([Access control](https://ferroehr.eu/docs/latest/viewer/access-control.html)).
