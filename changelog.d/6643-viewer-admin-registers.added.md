- The viewer's Access policy area shows the two admin registers, **Audit categories** and **Access delay**. Each tab shows the version in force with its committer and commit time, the document drawn by its members, and the history back to version 0, the default, where any version opens read-only. An administrator replaces a register's document in the code editor with `If-Match` naming the version read, and a `400` or `412` is drawn in the CDR's words ([Access control](https://ferroehr.eu/docs/latest/viewer/access-control.html#the-admin-registers)).
