- The admin marks API reads the three legal marks it could only set. `GET {ext}/admin/research-objection?ehr_id=` answers whether an objection to research processing stands, when the subject objected and any Art. 21(6) override ground. `GET {ext}/admin/retention/anchor?ehr_id=` answers the EHR's retention jurisdiction, anchor and EHR-wide hold. `GET {ext}/admin/retention/hold?ehr_id=` answers the EHR's objects held from disposal. Each read is admin-gated like its write and is an access record ([Admin & messaging APIs](https://ferroehr.eu/docs/latest/operations-admin-apis.html#legal-marks-restriction-objection-and-retention)).
