- The published `openehr-*` crates no longer enable `serde_json`'s `preserve_order` feature, so a project that depends on them keeps `serde_json`'s default sorted map unless it asks for insertion order itself. They still enable `float_roundtrip`, which the RFC 8785 form of a signed `VERSION` needs. The FerroEHR server and viewer keep `preserve_order`, so the JSON they answer is unchanged.
