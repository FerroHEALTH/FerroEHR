h|*Class*
2+^h|*ACCESS_DATA_SCOPE*

h|*Description*
2+a|A description of data in an EHR. Data match when they match every attribute that is set, and an attribute holding a list matches when any of its members does.

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*0..1*
|*objects*: `xref:{class_list}[List]<xref:{class_object_ref}[OBJECT_REF]>`
a|Individual versioned objects, such as one `VERSIONED_COMPOSITION`.

h|*0..1*
|*templates*: `xref:{class_list}[List]<xref:{class_string}[String]>`
a|Template identifiers the data were committed under.

h|*0..1*
|*archetypes*: `xref:{class_list}[List]<xref:{class_archetype_id}[ARCHETYPE_ID]>`
a|Root archetypes of the data; a specialisation of a named archetype matches too.

h|*0..1*
|*categories*: `xref:{class_list}[List]<xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]>`
a|Categories of the data, such as the EHDS priority categories, coded in a terminology the jurisdiction names.

h|*0..1*
|*sensitivities*: `xref:{class_list}[List]<xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]>`
a|Sensitivity codes, matched against the labels the data carry, coded in a terminology the system documents (such as the HL7 v3 confidentiality and sensitivity codes).

h|*0..1*
|*origins*: `xref:{class_list}[List]<xref:{class_string}[String]>`
a|The systems the data came from, as `FEEDER_AUDIT_DETAILS._system_id_` or the committing system's `_system_id_` records them.

h|*0..1*
|*recorded*: `xref:data_types:quantity_package.adoc#_dv_interval_class[DV_INTERVAL]<xref:data_types:date_time_package.adoc#_dv_date_time_class[DV_DATE_TIME]>`
a|When the data were committed.

h|*Invariants*
2+a|__Not_empty__: `objects /= Void or templates /= Void or archetypes /= Void or categories /= Void or sensitivities /= Void or origins /= Void or recorded /= Void`

h|
2+a|__Objects_valid__: `objects /= Void implies not objects.is_empty`

h|
2+a|__Templates_valid__: `templates /= Void implies not templates.is_empty`

h|
2+a|__Archetypes_valid__: `archetypes /= Void implies not archetypes.is_empty`

h|
2+a|__Categories_valid__: `categories /= Void implies not categories.is_empty`

h|
2+a|__Sensitivities_valid__: `sensitivities /= Void implies not sensitivities.is_empty`

h|
2+a|__Origins_valid__: `origins /= Void implies not origins.is_empty`
