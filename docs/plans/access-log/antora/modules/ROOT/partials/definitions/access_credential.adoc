h|*Class*
2+^h|*ACCESS_CREDENTIAL*

h|*Description*
2+a|A reference to a credential, by its issuer and the identifiers it carried, never the credential itself.

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*1..1*
|*issuer*: `xref:{class_string}[String]`
a|The issuer of the credential, such as an OAuth 2.0 authorization server's issuer identifier or a SAML IdP's entity id.

h|*1..1*
|*subject*: `xref:{class_string}[String]`
a|The subject the issuer named.

h|*0..1*
|*client_id*: `xref:{class_string}[String]`
a|The client the credential was issued to.

h|*0..1*
|*token_id*: `xref:{class_string}[String]`
a|The identifier of the token or assertion, such as a JWT `jti`.

h|*0..1*
|*assurance*: `xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]`
a|The assurance level of the authentication.

h|*0..1*
|*authentication_method*: `xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]`
a|The authentication method or context class the issuer stated.

h|*Invariants*
2+a|__Issuer_valid__: `not issuer.is_empty`

h|
2+a|__Subject_valid__: `not subject.is_empty`

|===
