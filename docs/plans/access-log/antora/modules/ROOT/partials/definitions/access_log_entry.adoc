h|*Class*
2+^h|*ACCESS_LOG_ENTRY*

h|*Description*
2+a|The record of one access event to the data of at most one EHR: who accessed, on whose behalf, what, when, why, under which authorisation, with which outcome, and through which channel. An access that reaches the data of several EHRs is recorded as one entry per EHR, and the entries of one request share `_channel.request_id_`.

h|*Inherit*
2+|`xref:access_log:access_log_package.adoc#_access_log_record_class[ACCESS_LOG_RECORD]`

^h|*Signature*
^h|*Meaning*
