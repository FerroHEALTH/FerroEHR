|*confidentiality*: `xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]`
a|The confidentiality the data carry, coded in the `HL7_Confidentiality` code system (`N` normal, `R` restricted, `V` very restricted).
