h|*Class*
2+^h|*ACCESS_LABEL*

h|*Description*
2+a|Labels on one versioned object of the EHR: sensitivity codes, a confidentiality, or both. A caller reads labelled data only when a permit clears every label, or an emergency override applies.

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*1..1*
|*target*: `xref:{class_object_ref}[OBJECT_REF]`
a|The versioned object the labels apply to.

h|*0..1*
|*sensitivities*: `xref:{class_list}[List]<xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]>`
a|The sensitivity codes the object carries.

h|*0..1*
|*confidentiality*: `xref:access_control:access_control_package.adoc#_confidentiality_marking_class[CONFIDENTIALITY_MARKING]`
a|The confidentiality of the object. The confidentiality of a datum is the highest of this marking, the marking of its EHR and the confidentiality its classifications give it.

h|*0..1*
|*reason*: `xref:data_types:text_package.adoc#_dv_text_class[DV_TEXT]`
a|Why the object is labelled, never clinical content.

h|*Invariants*
2+a|__Not_empty__: `sensitivities /= Void or confidentiality /= Void`

h|
2+a|__Sensitivities_valid__: `sensitivities /= Void implies not sensitivities.is_empty`

|===
