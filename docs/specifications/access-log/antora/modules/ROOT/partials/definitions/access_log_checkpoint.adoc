h|*Class*
2+^h|*ACCESS_LOG_CHECKPOINT*

h|*Description*
2+a|A signed statement by the recording system of the head of its log at a point in time. A checkpoint commits to every record up to `_sequence_`, so a verifier that holds it can detect a later rewrite of the log, and an export carries the checkpoint its records verify against.

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*1..1*
|*system_id*: `xref:{class_string}[String]`
a|The system whose log the checkpoint seals.

h|*1..1*
|*sequence*: `xref:{class_integer64}[Integer64]`
a|The `_link.sequence_` of the last record the checkpoint covers.

h|*1..1*
|*digest*: `xref:{class_string}[String]`
a|The `_link.digest_` of that record.

h|*1..1*
|*algorithm*: `xref:{class_string}[String]`
a|Name of the digest algorithm of the chain.

h|*1..1*
|*time_sealed*: `xref:data_types:date_time_package.adoc#_dv_date_time_class[DV_DATE_TIME]`
a|Time at which the checkpoint was signed.

h|*1..1*
|*signer*: `xref:common:generic_package.adoc#_party_proxy_class[PARTY_PROXY]`
a|The party, usually the organisation responsible for the system, whose key signed the checkpoint.

h|*1..1*
|*proof*: `xref:{class_string}[String]`
a|The signature over the checkpoint's other attributes, in the form `ATTESTATION._proof_` uses, such as a JWS or a PGP signature.

h|*Invariants*
2+a|__Sequence_valid__: `sequence >= 1`

h|
2+a|__Proof_valid__: `not proof.is_empty`
