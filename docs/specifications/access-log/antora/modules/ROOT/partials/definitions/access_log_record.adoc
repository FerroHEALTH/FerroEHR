h|*Class*
2+^h|*ACCESS_LOG_RECORD (abstract)*

h|*Description*
2+a|Abstract parent of the records of an access log. A record is never modified; when its retention period ends, the system replaces an `ACCESS_LOG_ENTRY` by an `ACCESS_LOG_TOMBSTONE` that keeps the uid and the time. The system seals windows of records in `ACCESS_LOG_CHECKPOINT`s, so a changed, removed or inserted record is found.

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*1..1*
|*uid*: `xref:{class_hier_object_id}[HIER_OBJECT_ID]`
a|Unique identifier of this record, assigned by the recording system.

h|*1..1*
|*system_id*: `xref:{class_string}[String]`
a|Identifier of the logical EHR system that recorded the access, with the meaning of `AUDIT_DETAILS._system_id_`.

h|*1..1*
|*time_recorded*: `xref:data_types:date_time_package.adoc#_dv_date_time_class[DV_DATE_TIME]`
a|Time at which the record was written to the log.

h|*Invariants*
2+a|__System_id_valid__: `not system_id.is_empty`
