2+a|How long an entry is kept, set when it is written from the access policy in force and the laws that bind its controller.

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*0..1*
|*retain_until*: `xref:data_types:date_time_package.adoc#_dv_date_class[DV_DATE]`
a|The last day the entry is kept; Void when it is kept without end.

|*grounds*: `xref:{class_list}[List]<xref:data_types:text_package.adoc#_dv_coded_text_class[DV_CODED_TEXT]>`
a|The provisions that set the period, such as a minimum period from the date of access and a national maximum, coded in a terminology the jurisdiction names.

h|*0..1*
|*policy*: `xref:{class_object_version_id}[OBJECT_VERSION_ID]`
a|The version of the controller's access policy the period was taken from; Void where the entry was kept under no policy, or was imported from another system.
