== Superseded

This specification has been superseded. Its content - the identification system for openEHR knowledge artefacts, covering human-readable and machine identifiers, versioning, lifecycle management, distributed governance, referencing and artefact authentication - has been relocated to the BASE component as the openEHR {openehr_base_artefact_identification}[Artefact Identification^] specification, which is now the normative source. The identifier types it defines are realised by the `Hrid` primitive in the openEHR {openehr_foundation_types}[Foundation Types^] specification and by `ARCHETYPE_ID` and `TEMPLATE_ID` in the openEHR {openehr_base_types}[Base Types^] specification.

Released versions of this document remain available with the corresponding AM releases.
