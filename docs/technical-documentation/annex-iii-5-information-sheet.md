# Annex III 5: a copy of the information sheet

EHDS Annex III point 5 (`docs/law/eu/ehds/text.html`): "A copy of the
information sheet referred to in Article 38."

The information sheet is
[`compliance/information-sheet.md`](../../website/book/src/compliance/information-sheet.md)
at the release tag. The same page is published in the book frozen for the
release at `https://ferroehr.eu/docs/vX.Y.Z/compliance/information-sheet.html`,
and attached to the GitHub release as the asset
`ferroehr-vX.Y.Z-information-sheet.md`, with the release's version and date
stamped in.

EHDS Art. 38(3) allows the information to be entered into the EU database of
Art. 49 in place of supplying the sheet with the system. FerroEHR is not
registered there (registration follows a declaration of conformity), so the
sheet is supplied with each release.

State: available.
